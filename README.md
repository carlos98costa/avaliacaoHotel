# Hotel

Avaliação Prática — Programação para Dispositivos Móveis II.

Aluno: Carlos Adriano Torquato da Silva Costa

Aplicativo Flutter de cadastro de hospedagens (valor da hospedagem e nº do quarto), adaptado do Projeto Bank. Os dados ficam somente em memória.

## Executar

```bash
flutter pub get
flutter run
```

## Evidências

- `evidencias/formulario.png`: tela de formulário com os campos preenchidos.
- `evidencias/lista.png`: lista após a confirmação do cadastro, exibindo o novo registro.
